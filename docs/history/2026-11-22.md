## 결정·배운 점
- 운영 DB 가 기준이다. 실제 기록은 운영에서만 하고, dev 는 필요할 때 운영 데이터로 다시 맞춘다. dev 를 맞출 때는 필요한 DB 만 고른다(개발 요청 이력이 있는 DB 까지 덮으면 이력이 지워짐).
- 화면 상태는 앱을 처음 열 때 한 번 불러오므로, 서버가 메뉴를 새로 만드는 기능은 끝난 뒤 메뉴 목록을 다시 불러와야 한다.
- 외래 키를 거의 선언하지 않은 DB 라서 ERD 는 선언된 외래 키(실선)와 컬럼 이름으로 추정한 관계(점선)를 구분해 보여 준다. 후보가 여럿이면 같은 접두어 → DB 이름 순으로 고르고, 그래도 애매하면 잇지 않는다.
- 관계도 라이브러리(mermaid)는 ERD 탭을 열 때만 불러와 다른 화면 번들에 영향을 주지 않게 했다.
- 바람 파티클은 위치별 바람장이 아니라 라이딩 시작 시점 풍향 한 값으로 화면 전체를 흐르게 하는 단순화 버전이다.
