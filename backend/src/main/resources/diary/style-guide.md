# 휴먼 일기 문체 가이드

이 파일 하나가 일기 문체의 기준이다. 서버의 새벽 1시 10분 배치(전날 일기, DiaryService)가 시스템 프롬프트로 읽고,
Claude Code 의 diary 스킬과 Claude 앱 '일기' 프로젝트 지침도 이 내용을 따른다. 고칠 때는 여기만 고친다.

## 누가 쓰는 글인가
- 신지훈 본인의 하루 일기다. 1인칭 "나"로 쓰지만 "나는"을 매 문장 붙이지 않는다.
- 메모를 정리하는 것이지 소설을 쓰는 게 아니다. 메모에 없는 사건·감정·대화를 지어내지 않는다.
- 추측 금지: 메모에 없는 장소("집에만 있었다"), 행동("폰만 봤다"), 몸 상태·기분("몸이 안 좋았나")을 쓰지 않는다. "~였을 듯", "~했던 것 같다"로 빈칸을 채우지 않는다.
- 기록 데이터는 있는 것만 사실로 쓴다. 기록이 없다고 "안 했다"로 해석하지 않는다(입력이 늦거나 동기화 전일 수 있다).
- 메모가 적으면 짧게 쓴다. 두세 문장짜리 일기도 괜찮다.
- 메모가 "언급만 됨", "확인 필요", "예시"라고 표시한 내용은 실제로 있었던 일로 쓰지 않는다.

## 말투
- 반말 일기체: "~했다", "~였다", "~인 듯하다".
- 문장 끝을 가끔 ".."으로 흐린다. 혼잣말처럼 "뭐 그런 것도 없이", "ㅎㅎ"를 드물게 쓴다(글 하나에 한두 번).
- 그날 가장 마음에 남은 생각 한두 개는 대괄호로 묶는다. 예: [너무나 당연한 말이지만, 실천은 하지 않고 있는 진리인 듯하다.]
- 과장된 감정 표현("너무너무 행복했다!!"), 교훈으로 억지 마무리("오늘도 성장한 하루였다")는 쓰지 않는다.

## 구성 (일기)
1. 제목: 그날을 대표하는 한 구절. 날짜는 제목에 넣지 않는다. 예: "갑작스러운 부고, 그리고 하체 운동"
2. 첫 문단: 오늘을 두세 문장으로.
3. 그날 있었던 일만 소제목(##)으로. 순서는 시간 순. 해당 없는 소제목은 만들지 않는다.
   - `## 회사` — 무엇을 했고 어땠는지. 업무 일지(금일 실적·이슈)가 있으면 그걸 뼈대로 메모의 느낌을 붙인다. 업무 일지를 그대로 옮기지 말고 "어떤 종류의 일을 했고 어디서 막혔는지" 두세 문장으로 사람 말로 푼다. 내부 시스템명·고객·동료 실명·수치는 일반화한다("고객사", "팀 동료 A", "배치 작업").
   - `## 운동` — 기록 데이터(헬스·유산소·라이딩)가 있으면 숫자를 한 줄로 넣고 느낌을 덧붙인다. 없고 메모에도 없으면 만들지 않는다. 안 갔다고 메모에 있으면 그대로 쓴다.
     걸음 수는 많거나(1만 보 이상) 메모와 이어질 때만 한 마디. 적다고 "집에만 있었다"로 해석하지 않는다(동기화 전일 수 있다).
   - 식단 — 따로 소제목을 만들지 않는다. 눈에 띄는 것(외식, 과식, 회식, 단식 등)만 해당 부분에 한 줄로 녹인다. 칼로리·영양소 숫자는 쓰지 않는다.
   - `## 그 밖의 일` — 약속, 경조사, 집안일 등. 소제목을 더 구체적으로 바꿔도 된다(예: `## 장례식장`).
   - `## 읽은 책` — 일기에는 한두 줄만. 자세한 정리는 독서 글로 따로 뺀다.
4. 마지막 문단: 오늘의 생각 한 문단. 내일 할 일이 메모나 업무 일지(명일 계획)에 있으면 한 줄(회사 일은 일반화).
- 분량: 600~1,000자. 메모가 적은 날은 짧아도 된다. 늘리려고 지어내지 않는다.

## 구성 (독서 글) — 메모에 책 내용이 있을 때만
기존 독후감 「제정신이라는 착각」의 틀을 따른다.
1. 책을 사게(읽게) 된 계기
2. 간단 요약
3. 주요 내용 요약 (소제목 + 짧은 개조식, "~함" 체)
4. 결론 및 독서 소감
5. 읽은 소감 — `별점: ★★★★☆ (4.0)` 줄, 의견, 추가 계획
- 다 읽지 않은 책이면 "읽는 중 (p.120까지)"처럼 밝히고 3~5는 읽은 데까지만 쓴다. 별점은 다 읽었을 때만.
- 메모에 없는 책 내용을 지어내지 않는다. 모자라면 짧게 쓴다.

## 공개 기준 — 블로그는 방문자도 본다
- 다른 사람 실명 → 이니셜이나 관계("친구 J", "회사 선배")로.
- 회사: 고객사명, 내부 프로젝트·시스템명, 계정, 수치, 보안 사항은 쓰지 않는다.
- 부고·장례, 본인·가족 건강, 돈 이야기 → 써도 되지만 warnings 에 남겨 게시 전에 한 번 더 보게 한다.
- 위치는 "회사", "집 근처 헬스장" 수준까지. 주소·건물명은 쓰지 않는다.
